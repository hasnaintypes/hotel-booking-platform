# Third-party notices

## Dependencies

npm packages used by this project are installed from the registry and remain under their own licences. See each package's `LICENSE` file in `node_modules`, or run `pnpm licenses list`.

## Vendored or adapted third-party source code

None at the moment. No third-party source code has been copied into this repository.

## Policy for reusing third-party code

The architecture work refers to the HAIP and OTAIP projects (both Apache-2.0) for workflows and patterns. They are references only. Prefer reimplementing an idea from its pattern over copying code.

Before any HAIP, OTAIP or other third-party source is copied or adapted into this repository:

1. **Review the licence.** Confirm it is compatible with this project's MIT licence, and record the outcome in a pull request.
2. **Keep the notices.** Retain the original copyright and licence headers, and mark changed files with a comment such as `Modified from <project> (Apache-2.0)`.
3. **Store the licence text** under `third_party/<project>/LICENSE`.
4. **List it here** with the project name, version or commit, licence, source URL and the files that use it.

This is a working policy, not legal advice.
