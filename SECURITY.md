# Security Policy

## Supported versions

This project is maintained on a best-effort basis. Security fixes are applied to the latest `main` branch only.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security vulnerability.

Report it privately through GitHub:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**
   ([direct link](https://github.com/hasnaintypes/hotel-booking-platform/security/advisories/new)).
3. Describe the problem and submit. Only the maintainer can see the report.

Please include:

1. A description of the issue and its potential impact.
2. Steps to reproduce (a proof of concept or sample requests and responses).
3. The affected component (web app, admin app, API, authentication, payments, deployment configuration).
4. A suggested severity, if you have one.

Do not include real credentials, real card numbers or other people's personal data in a report. Use Stripe test keys and a disposable database when reproducing payment issues.

## What to expect

- Acknowledgement of your report, usually within a few business days.
- A fix or mitigation plan once the issue is confirmed.
- Credit in the release notes if you want it, after the fix is published.

Please give the maintainer reasonable time to fix an issue before disclosing it publicly.
